# Dota 2 CLI — практичне заняття 14

Навчальний консольний застосунок на C# / .NET 8: каталог героїв Dota 2 та покрокова текстова бойова гра. Проєкт демонструє парсинг JSON, розділення бізнес-логіки й інфраструктури, Dependency Injection через конструктори, збереження стану та журналювання бою.

## Запуск

1. Встановіть .NET 8 SDK.
2. Відкрийте термінал у папці `Dota2CLI_Project`, де розташований `Dota2CLI.csproj`.
3. Виконайте:

```bash
dotnet restore
dotnet run
```

4. Введіть `help`, щоб переглянути команди.

## Команди

| Команда | Дія |
|---|---|
| `help` | Показати довідку |
| `refresh` | Завантажити каталог із OpenDota API (потрібен інтернет) |
| `heroes` | Показати всіх персонажів |
| `hero axe` | Показати характеристики персонажа |
| `create` | Створити локального персонажа через діалог |
| `search agility` | Пошук за ім'ям, ID, атрибутом або типом атаки |
| `play axe lina` | Почати бій між двома персонажами |
| `play` | Вибрати персонажів через діалог |
| `act attack` | Атакувати в кожній запланованій дії гравця поточного раунду |
| `act heal` | Відновлювати 20 HP у кожній запланованій дії гравця |
| `act defend` | Активувати захист у кожній запланованій дії гравця |
| `act status` / `status` | Показати стан без витрати дії |
| `history` | Показати журнал дій з порядком усередині раунду |
| `save` | Зберегти поточний стан бою |
| `load` | Завантажити останній збережений бій |
| `results` | Показати результати завершених боїв |
| `exit` | Завершити програму |

## Швидкість і раунди

Кількість дій за раунд дорівнює `max(1, floor(Speed / 100))`. Час дії `k` дорівнює `(k * 100) / Speed`. Тому Speed 150 дає одну дію раніше за Speed 100, а Speed 200 — дві дії, одна з яких відбувається між діями повільніших учасників. Детальна формула та правила нічиєї описані в `DESIGN_DOCUMENT.md`.

Одна команда `act` запускає повний раунд: обрана дія гравця виконується для кожної його дії в розкладі, суперник автоматично атакує у свої часові позиції. Якщо один із персонажів втрачає все HP, решта дій скасовується.

## Збереження

Після першого запуску створюється папка `Data`:

- `heroes.json` — каталог, включно з локальними персонажами;
- `game-state.json` — учасники, копії бойових профілів, HP, номер раунду, прапорці та історія;
- `game-results.txt` — результати завершених боїв.

Стан автоматично зберігається після кожного раунду. Команди `save` та `load` дозволяють керувати ним вручну. Профілі учасників копіюються на початку бою, тому наступне оновлення каталогу не змінює характеристики вже розпочатого матчу.

## Автоматизовані тести

Тестовий проєкт не потребує сторонніх NuGet-пакетів. Запуск із кореневої папки:

```bash
dotnet run --project Tests/Dota2CLI.Tests.csproj
```

Перевіряються парсинг JSON API, формула шкоди, порядок швидкості 150/100, додаткова дія швидкості 200, обмеження лікування, одноразовий захист, знімки профілів і відновлення збереження.

## Примітки щодо API

Використано дозволену альтернативу `https://api.opendota.com/api/heroes`. API повертає ID, ім'я, атрибут і тип атаки. HP, Attack, Armor, Resist та Speed не повертаються цим endpoint і тому мають навчальні тестові значення. Для GUI передбачено нейтральну модель `HeroCardData`; окремий графічний інтерфейс не входить до цієї практичної роботи.
