# Dota 2 — CLI та графічний застосунок

Навчальний застосунок на C# / .NET 8 із консольним і графічним інтерфейсами: каталог героїв Dota 2 та проста покрокова бойова гра. Це навчальний прототип, а не офіційний клієнт Dota 2.

## Запуск

### Графічна версія (основний варіант)

1. Відкрийте папку `publish\\win-x64`.
2. Запустіть файл `Dota2GUI.exe` подвійним клацанням.
3. Для запуску готового автономного EXE-файлу окремо встановлювати .NET Runtime не потрібно. Збірка призначена для Windows x64.

### Консольна версія

Якщо у збірці надано `Dota2CLI.exe`, його можна запустити окремо для роботи з командами, наведеними нижче.

Для розробки та повторного збирання проєкту потрібен .NET 8 SDK; кінцевому користувачеві готового `Dota2GUI.exe` SDK не потрібен.

## Команди

* `help` — показати всі команди.
* `refresh` — оновити каталог героїв через OpenDota API.
* `heroes` — список героїв.
* `hero axe` — характеристики героя та посилання на графіку.
* `create` — додати власного героя через діалог.
* `search agility` — пошук за ім'ям, ID, атрибутом або типом атаки.
* `play` — вибрати героїв через діалог; `play axe lina` — почати бій із заданими героями.
* `act attack`, `act heal`, `act status` — виконати дію або переглянути стан.
* `status` — показати стан бою.
* `results` — показати історію результатів.
* `exit` — завершити програму.

## Збереження

Файли даних зберігаються окремо від EXE-файлу в системній папці `%LOCALAPPDATA%\\Dota2CLI`:

* `heroes.json` — каталог героїв, включно з користувацькими.
* `game-state.json` — останній стан бою.
* `game-results.txt` — історія завершених боїв.

Для оновлення каталогу потрібне підключення до інтернету. Застосунок використовує відкритий OpenDota API та не потребує API-ключа. Це навчальний прототип: він не підключається до клієнта гри Dota 2.



## Збирання для розробника

Щоб повторно створити автономний пакет для Windows x64, потрібні Windows 10/11, PowerShell і .NET 8 SDK. У кореневій папці проєкту виконайте:

```powershell
powershell -ExecutionPolicy Bypass -File .\\build-release.ps1
```

Скрипт збірки та детальніші відомості про розгортання описані в `DESIGN_DOCUMENT.md` (розділ 13). Інструкції з перевірки наведені в `TESTING.md`.
