# Dota 2 CLI

Навчальний консольний застосунок на C# / .NET 8: каталог героїв Dota 2 та проста покрокова текстова бойова гра. Це навчальний прототип, а не офіційний клієнт Dota 2.

## Запуск
1. Встановіть .NET 8 SDK.
2. Відкрийте термінал у папці з `Dota2CLI.csproj` (файл проєкту має таку назву, але застосунок присвячений Dota 2).
3. Виконайте `dotnet restore`, а потім `dotnet run`.
4. Введіть `help`, щоб побачити команди.

## Команди
- `help` (також `--help` або `-h`) — показати всі команди. Назви команд не залежать від регістру.
- `refresh` — завантажити актуальний список героїв з OpenDota API та зберегти каталог локально (потрібен інтернет).
- `heroes` — список героїв.
- `hero axe` — характеристики героя та пряме посилання на файл зображення героя.
- `create` — додати власного героя через діалог.
- `search agility` — пошук за ім'ям, ID, атрибутом або типом атаки.
- `play` — вибрати героїв через діалог; `play axe lina` — почати бій із заданими героями.
- `act attack`, `act heal`, `act status` — виконати дію або переглянути стан.
- `status` — показати стан бою.
- `results` — показати історію результатів.
- `exit` — завершити програму.

## Збереження
Після першого запуску програма створить папку `Data`:
- `heroes.json` — каталог героїв, включно з користувацькими.
- `game-state.json` — останній стан бою.
- `game-results.txt` — історія завершених боїв.

Якщо локального каталогу ще немає, застосунок створює початковий набір тестових героїв. Команда `refresh` завантажує список героїв з OpenDota API, оновлює локальний каталог і зберігає користувацьких героїв, які не дублюються з віддаленим списком. Якщо мережа недоступна або API повертає помилку, застосунок повідомляє про це й залишає попередній каталог без змін. Для стандартних героїв виводиться пряме посилання на зображення; консоль показує URL текстом, а не відображає саму картинку. Програма не підключається до гри Dota 2 і не потребує API-ключів.
